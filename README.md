# Unit-III Java Server Pages — Complete Notes

Interactive study notes for **Advanced Java (JSP)** covering theory, diagrams, Tomcat 11 deployment, and 4 ICA practicals with Trace / Source / Deploy / Run online labs.

## Live demo (public — no login required)

**https://jsp-vercel.vercel.app**

Also: **https://jsp-notes.vercel.app**

GitHub: **https://github.com/sagarh45/jsp-notes-unit-iii**

## Contents

- **Theory** — Introduction, JSP vs Servlet, life cycle, elements, directives, tags, exception handling, scopes, real applications
- **Diagrams** — Architecture, lifecycle, elements, implicit objects, exception flow
- **ICA practicals** — Industry-based programs with Tomcat 11 deploy steps
- **Simulator** — Browser-based JSP runtime for learning (no Tomcat needed for Run online)

## Run locally

Open `index.html` in a browser, or use any static server:

```bash
npx serve .
```

Then open `http://localhost:3000`

## Tomcat (real JSP execution)

For actual JSP on Tomcat 11.0.24, copy programs to `webapps/jsp/` and see the **Deploy** button in each lab on the notes page.
